# План

**Моя цель в этом проекте:** создать систему управления четырьмя шаговыми двигателями с использованием контроллера и сервоприводов.

**Мои задачи на ближайшее время в проекте:**

1. Подобрать сервоприводы, драйверы шаговых двигателей, контроллер и питание по расчётам.
2. Запустить NEMA17 колонны, настроить поиск нуля по концевику.
3. Запустить оба сервопривода, задать допустимые углы и плавное движение.
4. Настроить открытие, закрытие, поиск нуля и ограничение хода.
5. Объединить четыре привода в одной программе.
6. Добавить сохранённые положения и цикл «подойти → взять → перенести → отпустить».
7. Провести повторные переносы, измерить разброс положения, настроить скорости.
8. Подготовить демонстрацию, схему подключения и инструкцию запуска.
